# RevitCreateZhuk

Плагин для Revit 2024 создаёт семейство типовой аннотации «жук» по DWG. Если открыто редактируемое семейство категории «Типовые аннотации», команда строит схему в нём. На стартовом экране Revit или в проекте команда создаёт отдельный RFA.

## Установка

1. Для чтения DWG нужен .NET 8 Runtime x64. В папке `dist` должны находиться DLL плагина и каталог `DwgReader` целиком.
2. Закройте Revit 2024. Из папки RevitCreateZhuk запустите:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install.ps1
   ```

3. Запустите Revit. Кнопка **Создать схему-жук** находится на вкладке **Надстройки → RevitCreateZhuk**. Папку с плагином можно перенести, повторно запустив скрипт из нового места.

## Создание схемы

1. Нажмите **Создать схему-жук** и выберите DWG. Шаблон RFT «Типовая аннотация» мастер ищет в каталогах шаблонов Revit. Если путь пустой, укажите чистый шаблон вручную. Для работы в текущем семействе RFT используется для вложенных аннотаций.
2. В списке **Схема в файле** выберите нужный участок DWG. Мастер включает первую схему с приоритетом по наличию подписей и осей и добавляет участки разрезов, фасадов и паркинга с совпадающим внешним контуром. Каждый участок можно включить или исключить отдельно. **Совместить связанные схемы** переносит обозначения на основной контур. При выключенном флажке сохраняются координаты DWG. Точка вставки схемы находится у нижнего левого угла основного контура.
3. Если контур паркинга лежит отдельно, добавьте его через **Другой DWG…** под списком паркинга. Уровни из основного DWG сразу видны в списке **Паркинг** и включены в построение. При необходимости снимите флажок у уровня. Для контура без подписи добавьте строку «Паркинг -1», выберите контур и включите схему. Для совпадающих уровней дополнительный DWG имеет приоритет. При совмещении одинаковые контуры накладываются точно, разные совмещаются по нижнему левому углу выбранного контура. Для отдельного файла учитывается его INSUNITS. Если единицы не заданы, применяются единицы основного чертежа.
4. Проверьте имена построек и соответствие подсвеченных контуров. Можно отключить строку, поменять название или назначить контур. Если подпись отсутствует, добавьте строку с названием и номером контура. Правки названий задают имена параметров, исходный текст подписи переносится из DWG.
5. Проверьте единицы и масштаб. Начальный масштаб 1:1000, единицы берутся из INSUNITS, при их отсутствии подставляется 1 мм на единицу. Штриховка замкнутых контуров включена по умолчанию.
6. Откройте **Подписи разрезов / фасадов…**, чтобы изменить текст в столбце **Текст на схеме** и задать X и Y в миллиметрах на листе. Для переноса строки используйте `\n`. Пустое поле возвращает подпись из DWG. Положительные значения сдвигают текст вправо и вверх. Смещение действует только на текст.
7. Нажмите **Применить**. Для нового семейства укажите имя и путь RFA. Текущее семейство после проверки сохраните в Revit.

## Видимость и результат

- Подписи разрезов и фасадов по умолчанию создаются обычными текстовыми примечаниями в семействе. Их можно выбрать и переместить после построения. Чтобы текст скрывался вместе с линиями и стрелками, снимите флажок «Создавать подписи разрезов и фасадов обычным текстом». При повторном построении с тем же DWG прежние примечания плагина заменяются, поэтому ручные смещения нужно повторить или задать в мастере.

- В типах семейства отображаются названия построек, уровни паркинга, отдельные разрезы и фасады, «Оси», «Основная надпись», «Подписи» и «Подписи пристроек». Флажки и расчётные параметры плагина являются параметрами экземпляра. После загрузки семейства в проект флажки можно менять в свойствах выбранной аннотации. Редактируемые флажки находятся в Visibility, расчётные параметры с формулами — в Other. При повторном построении мастер обновляет группы существующих параметров. Уровни паркинга по умолчанию выключены. При включении уровня его подпись и штриховка заменяют подписи и штриховку наземных построек. Старые служебные параметры при замене того же DWG удаляются, если они больше нигде не используются.
- Геометрия, текст и формулы хранятся в RFA. Мастер сначала создаёт линии, дуги, текст и линии штриховки в основном семействе. Если нативный элемент нельзя связать с флажком видимости, мастер объединяет такие элементы во вложенную аннотацию по общему флажку. В отчёте указано число вложенных семейств. Мастер автоматически выполняет временный импорт DWG через Revit и откатывает этот импорт. Построение использует геометрию и семантику CAD-объектов, прочитанных отдельным процессом.
- Повторное применение того же пути DWG в том же виде заменяет сгенерированные экземпляры схемы. Параметры уже существующих типов сохраняют свои значения. Параметры, от которых зависят другие формулы или элементы, сохраняются.
- Оси и размеры переносятся как условные обозначения схемы. Размеры содержат геометрию и текст значения DWG. Они не пересчитываются после изменения линий в Revit.
- Распознавание опирается на слои, имена блоков, типы CAD-объектов и положение подписей относительно контуров. Для общих элементов в одной схеме используются флажки всех включённых построек, если для элемента нельзя определить отдельную постройку. Внешние ссылки, листы DWG и неподдерживаемые объекты перечисляются в пределах доступной информации парсера. Мастер показывает счётчик пропусков и список обнаруженных типов. Оформленные кольца осевых марок создаются дугами. Остальные дуги и окружности переносятся отрезками, штриховка строится тонкими диагональными линиями. Сложное CAD-форматирование текста упрощается.

## Исходники и сборка

- `src/Core` — модель DWG, классификация и подготовка групп. Не зависит от Revit API.
- `src/DwgReader` — чтение DWG через ACadSharp 3.7.16 в отдельном .NET 8 процессе. Изоляция исключает загрузку CAD-библиотеки и её зависимостей в Revit 2024.
- `src/Revit` — мастер, вход через ленту, создание RFA, транзакции и параметры видимости.

Для сборки нужны SDK .NET 8 или новее, targeting pack .NET Framework 4.8 и Revit 2024.

```powershell
.\Build.ps1 -Revit2024Dir 'D:\Programs\Revit 2024'
```

Параметр `-NuGetSource` позволяет указать доступный локальный источник пакетов. Сборка кладёт установочные файлы в `dist`.

## Проверка

На трёх DWG из родительской папки проверены чтение геометрии, выделение зон, распознавание осей и сопоставление подписей с контурами. Для основного участка исходника и версии `_2` найдено по пять подписей построек. В версии `_prk` найдены две схемы паркинга с разными уровнями. Сборка использует локальный Revit 2024 API. Для приёмки в Revit выполните команду со стартового экрана, сохраните новый RFA, переключите флажки в **Типах семейства** и повторите импорт в открытом RFA.


Для чертежа «Дом ЮС 4.2 (задание на жука).dwg» в локальной проверке найдены четыре разреза с обозначениями на обоих концах, шесть фасадов, два уровня паркинга, 24 осевых кольца и пять контуров штриховки. Версия _2 содержит сокращённый набор исходной графики.
